# Security Policy

If you believe you have found a security vulnerability in Instoryview or one of these repositories, please email **support@instoryview.com** with the subject "Security". Include the steps to reproduce and what you observed.

Please do not open a public issue for a vulnerability, and do not access data that is not yours. We will acknowledge your report and keep you updated while we investigate.

Never post an Instoryview API Key in an issue, discussion or pull request. If you leaked one, revoke it in [Developer settings](https://instoryview.com/settings/developers).
