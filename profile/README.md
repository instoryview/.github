# Instoryview

Instagram follower tracking, a free story viewer and developer tools. [instoryview.com](https://instoryview.com)

| | |
|---|---|
| [**cli**](https://github.com/instoryview/cli) | Command line for your tracked accounts. `npm i -g instoryview` |
| [**skill**](https://github.com/instoryview/skill) | Agent Skill for Claude Code, Codex, Cursor. `npx skills add instoryview/skill` |
| [**chatgpt-plugin**](https://github.com/instoryview/chatgpt-plugin) | ChatGPT / Codex Plugin preview and MCP connection |
| [**app**](https://github.com/instoryview/app) | Android and iOS app |
| [**story-viewer**](https://github.com/instoryview/story-viewer) | Free Instagram story viewer |

Docs: [instoryview.com/docs](https://instoryview.com/docs) · Open API: [instoryview.com/docs/reference](https://instoryview.com/docs/reference) · Support: support@instoryview.com
